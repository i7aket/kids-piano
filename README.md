# Kids Piano

One-hand melodies for kids. Six songs with finger numbers, lyrics under every
note, and a Web Audio piano. Single HTML file, no build step.

- The syllable you should sing right now turns red as the melody plays.
- Falling snow in the background.
- Tempo slider, pause and resume, restart.
- Keyboard: `1`–`6` or `A S D F G H`, space plays and stops.

Live: https://i7aket.github.io/kids-piano/
