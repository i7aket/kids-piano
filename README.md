# Kids Piano

One-hand melodies for kids. Seven songs with finger numbers, the song text under
the notes, and a Web Audio piano. Single HTML file, no build step.

- Every note square is the same size, showing the note letter and the finger.
- The song text keeps whole words; the syllable to sing right now turns red.
- Falling snow in the background, skipped under prefers-reduced-motion.
- Tempo slider, pause and resume, restart.
- Keyboard: `1`-`6` or `A S D F G H`, space plays and stops.

Songs: Snowflake Snowflake, Jingle Bells, Twinkle Twinkle Little Star,
Row Row Row Your Boat, Are You Sleeping Brother John, Rain Rain Go Away,
A Ram Sam Sam.

Live: https://i7aket.github.io/kids-piano/
